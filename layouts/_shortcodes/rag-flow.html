{{- /* Interactive, step-through RAG query flow. Usage in a post: {{< rag-flow >}} No libraries. Colours come from the site's CSS variables, so it follows light and dark mode. Without JavaScript the text diagram in the post still explains the same flow. */ -}} {{- $id := printf "ragflow-%d" .Ordinal -}}
  1. Question arrives
  2. Rewrite follow-up into a standalone question
  3. Exact-match cache check
  4. ↳ cache hit: return the stored answer
  5. Vector search: top 10 small chunks
  6. Cross-encoder rerank and filter
  7. ↳ nothing relevant: refuse
  8. Swap in parent passages, apply token budget
  9. Route to a small or large model
  10. Generate the answer with citations
  11. Judge scores the answer
  12. Record usage, cache the answer
